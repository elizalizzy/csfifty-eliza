# DREAM-PHOTOBOOTH WEB APP
### Video:  <https://youtu.be/bJUZ-SuI314>
## Description: 📸 Project Description
For my CS50 Final Project, I created a web-based photobooth application inspired by the very first week of the course, Scratch, specifically the live camera feature. When I first encountered that concept, I was fascinated by how a camera could be integrated into an interactive digital experience. That initial inspiration stayed with me throughout the course and eventually became the foundation for this final project.

This project is a dream/night-themed photobooth web application built entirely with HTML, CSS, and JavaScript. The goal of the application is to allow users to take photobooth-style pictures directly from their browser, decorate them with a chosen theme, and download the final photo to their local files.
I paid close attention to mood, visual design, and user experience.

### Home Screen

When the user first opens the website, they are greeted with a simple opening screen that displays the word 'Select'. Clicking 'Select' takes the user to the main camera page, where the photo taking starts.

### Choosing the Theme

Once inside the photobooth, the user can choose a theme. There are three themed options, plus one additional option with no theme at all. The “none” option removes all frames, allowing users to take a clean photo.


## Photo Capture System

Since this project is a photobooth, the photo-taking process is one of the most important features.

#### The camera page contains two photo sections:

+ Top photo
- Bottom photo

### Step-by-step photo flow

+ the top live camera preview appears first
- click the 'Capture' button at the bottom of the screen
+ 3-second countdown timer starts
- countdown ends, the top photo is captured
- then, the bottom live camera preview turns on
    - (uses the same camera system)
- The bottom photo is captured


## Download or Go Back

After both photos are taken, the application automatically moves to the final page. On this page, the user is given two choices:

- **Download the photo** <br>
The photo is downloaded directly to the user’s local file as jpeg

- **Go back to home** <br>
If not satisfied with result, can return to the home page and start over
